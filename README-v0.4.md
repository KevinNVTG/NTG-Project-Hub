# NTG Project Hub v0.4 Update

Adds the Residential Contract Builder and one-click Estimate -> Contract conversion.

Highlights:
- Contract numbering (`CON-26-0001`)
- One contract per source estimate
- Editable client, project, scope, price, schedule, and additional terms
- Editable payment milestones with schedule-total check
- Approved NTG residential contract clauses and warranty
- Spacious signature/date areas for client signing
- Project and contract numbers in the printed document header
- Contract status: Prepared, Sent, Signed, Void
- Project contract value updates automatically on conversion
