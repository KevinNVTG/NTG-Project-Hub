# NTG Project Hub v0.11.2 — Estimated T&M Budget by Area

Install after v0.11.1.

Adds customizable Area / Phase breakdowns to Commercial Proposals. Each area can receive estimated ST/OT/DT hours by the existing master Union / T&M labor classifications, so labor billing rates are entered only once. Pricing/allowance items can also be assigned to an area.

Customer print/PDF adds a professional **Estimated T&M Budget by Area** table with estimated union hours, estimated union labor, material allowances, other T&M/pricing, and estimated area total. It is explicitly identified as budgetary; actual billing remains T&M under the proposal terms.
