# NTG Project Hub v0.4.1

This patch makes Residential Contract Section 6 (Contractor Expenses) customizable for every job.

- Adds a Contractor Expenses field to the Contract Builder.
- Section 6 in Print / PDF now uses that project-specific text instead of the old example list.
- New contracts start with the field blank so the project-specific expense list is intentional.
- The field remains fully editable before the contract is sent or signed.
