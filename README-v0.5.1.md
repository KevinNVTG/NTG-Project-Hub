# NTG Project Hub v0.5.1 - Form Layout Fix

This patch improves form readability throughout NTG Project Hub and fixes the crowded Purchase Order editor.

Changes:
- PO Details now appears below the line-item workspace instead of beside it.
- Existing and new PO line items use spacious multi-row editors.
- Description fields span the full line-item width.
- Customer, project, vendor, contract, estimate, and PO inputs are taller and use larger readable text.
- Standard edit forms use more of the available screen width.
- Two-column forms collapse earlier on narrower screens.
- Mobile form controls remain easy to read and tap.

No Supabase migration is required for this update.
