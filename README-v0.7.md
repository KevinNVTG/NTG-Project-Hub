# NTG Project Hub v0.7 - Change Orders

Adds contract-linked change orders with automatic numbering, printable NTG change-order documents, approval workflow, project activity history, and automatic revised contract/project values.

## Workflow
Contract -> + Change Order -> Edit revision -> Print / PDF -> Approve & Apply to Contract

Once approved, the change order is locked and its amount is applied to the linked contract and project total.
