# NTG Project Hub v0.5.2 - UI Readability & Layout Polish

This CSS-only update fixes cramped and vertically wrapped text throughout the application.

## Changes
- Customer directory and Add Customer editor are stacked vertically so each gets full workspace width.
- Customer names, types, email addresses, phone numbers, and View links read left-to-right.
- Data tables keep sensible column widths and scroll inside their card on smaller screens instead of stretching the whole page.
- Removed aggressive letter-by-letter wrapping from table cells.
- Customer and general forms use comfortable two-column fields on wide screens and one column on smaller screens.
- Estimate, Contract, and Purchase Order editors use full-width vertical layouts instead of narrow side panels.
- Prevented application-wide horizontal overflow caused by nested grid minimum widths.
- No database changes.
