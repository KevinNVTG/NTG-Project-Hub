# NTG Project Hub v0.10.4 — Proposal Introduction Presets

Install after v0.10.3.

Adds one-click editable executive-summary presets to the Commercial Proposal Builder:
- Standard Commercial
- T&M / Union
- Tile Only
- Stone Only
- Tile + Stone
- Clear

Choosing a preset only fills the Executive Summary / Proposal Introduction field. The wording remains fully editable before saving.

No Supabase migration is required.

Suggested commit message:
`Add commercial proposal introduction presets v0.10.4`
