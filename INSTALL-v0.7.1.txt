NTG Project Hub v0.7.1 installation

1. Extract this ZIP.
2. Copy everything INSIDE the extracted update folder into your local NTG-Project-Hub repository.
3. Choose Replace/Merge when Windows asks.
4. In GitHub Desktop use commit summary:
   Add safe change order corrections v0.7.1
5. Commit to main, then Push origin.
6. Supabase should apply 202608310001_change_order_corrections.sql automatically.
7. Wait for Vercel to show Ready.
8. Open the approved change order, correct the amount, enter a required Correction Note, and click Save Approved CO Correction.

Do not manually subtract the old amount or create another change order for the typo. The correction workflow calculates the difference automatically.
