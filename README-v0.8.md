# NTG Project Hub v0.8 - Invoicing & Payments

Adds contract-connected customer invoicing and payment tracking.

## Included
- Invoice numbering: `INV-YY-0001`
- Create invoices from contract payment milestones
- Create invoices from approved change orders
- Progress/custom invoices
- Final-balance invoices calculated from contract value less prior non-void invoices
- Editable invoice line items
- Professional NTG customer Print / PDF invoice
- Record check, ACH, cash, card, wire, or other payments
- Paid / partially paid / sent / overdue / void statuses
- Contract financial panel showing invoiced, paid, and remaining to invoice
- Dashboard Accounts Receivable and Payments Collected
- Invoices sidebar section
